# 🏥 МедУчёт - Единая база данных в Google Sheets

Полноценная система управления медицинским снабжением выездного подразделения с интеграцией Google Sheets в качестве базы данных.

## 📖 О проекте

Система "МедУчёт" состоит из двух приложений:
- **Приложение руководителя** - управление сотрудниками, контроль расходов, отчёты
- **Приложение кладовщика** - управление номенклатурой, приходами, остатками, возвратами

Оба приложения используют единую базу данных в Google Sheets.

- ✅ Приходы к сотрудникам
- ✅ Расходы у сотрудников с контролем лимитов
- ✅ Остатки у сотрудников

- ✅ Журнал изменений
- ✅ Архив

### Приложение кладовщика

- ✅ Управление номенклатурой с ценами

- ✅ Расходы с фильтрацией по типу

- ✅ Отчёты
- ✅ Архив

## 📊 Структура базы данных

### 11 листов Google таблицы:

1. **Сотрудники** - данные 30 сотрудников
2. **Номенклатура** - 20 позиций (лекарства, ПКУ, оборудование, расходники)
3. **История цен** - изменения цен на номенклатуру
4. **Приходы** - денежные приходы сотрудникам
5. **Пациенты** - данные пациентов
6. **Расходы** - расход материалов на пациентов
7. **Начальные остатки** - остатки на начало периода
8. **Возвраты** - возвраты материалов
9. **Сообщения** - переписка между сотрудниками
10. **Журнал** - история всех изменений
11. **Уведомления** - системные уведомления

Подробная структура: [GOOGLE_SHEETS_DATABASE.md](GOOGLE_SHEETS_DATABASE.md)

## 💡 Основные функции

### Расчёт остатков

```typescript
Остаток = Начальные_остатки - Расходы - Возвраты
```

### Расчёт цены для ПКУ

```typescript
Цена_за_единицу = Цена_за_упаковку / Количество_в_упаковке
```

### Контроль лимита 6%

```typescript
Лимит = Стоимость_терапии × 0.06
if (Сумма_препаратов > Лимит) {
  // Превышение лимита
}
```
